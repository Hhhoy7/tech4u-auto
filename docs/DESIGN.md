# التصميم التقني — نظام TECH4U لإدارة قناة يوتيوب بالذكاء الاصطناعي
المرحلة الأولى (دراسة وتصميم) · الحالة: **بانتظار موافقتك** · لم يُنشأ أي كود جديد ولم يُشترَك بأي خدمة.

> كل الأرقام المالية أدناه **تقديرات تخطيطية** من معرفتي بالأسعار، وليست عروض أسعار. تُراجَع على صفحات التسعير الرسمية قبل أي اشتراك، ولن أشترك بشيء دون موافقتك.

## 1. ما وجدته (الفحص)

**المستودع `tech4u-auto` فيه خط إنتاج يعمل جزئياً (576 سطراً بايثون):**
موضوع ← سيناريو (Claude) ← صوت (ElevenLabs) ← لقطات ستوك (Pexels/Pixabay) ← ffmpeg ← ترجمة ASS ← صورة مصغرة (Pillow) ← رفع YouTube، ويعمل يومياً عبر GitHub Actions. `state/published.json` فارغ، أي لم يُنشر شيء بعد. الخط الحالي فيديو واحد طويل يومياً، بلا Shorts ولا تحليلات ولا لوحة تحكم ولا ذاكرة قرار.

**البيئة التي فحصتها (حاوية السحابة التي أعمل فيها، لا جهازك):** Python 3.13، Node 22، ffmpeg 6.1، Docker، PostgreSQL client، 4 أنوية، 15GB RAM، **بلا GPU**. أي أنها تكفي للمونتاج بـ ffmpeg والتنسيق، ولا تكفي لتوليد فيديو محلياً؛ توليد الفيديو يجب أن يكون عبر API خارجي. الحاوية مؤقتة، فالتشغيل الدائم يحتاج مضيفاً آخر (انظر 3).
لم أفحص جهازك الشخصي لأنه غير موصول بالجلسة؛ لا حاجة له إن اعتمدنا الاستضافة السحابية.

**موصلات متاحة لي في هذه الجلسة:** n8n، Halai (توليد صور/فيديو/صوت)، Metricool، Google Drive، Supabase، Canva، Gmail، Google Calendar.

**⚠️ تنبيه مهم عن n8n:** حساب n8n المتصل بي هو **نسخة إنتاج لمتجرك FLORYA** (67 سير عمل: واتساب، Shopify، مزامنة مخزون، إلخ). فيه اعتمادات Telegram وGemini وMeta، **وليس فيه** اعتمادات YouTube ولا ElevenLabs ولا Anthropic. توصيتي: **لا نبني القناة داخل نسخة المتجر**؛ نُنشئ نسخة n8n منفصلة (أو مشروعاً معزولاً) كي لا يؤثر خلل في القناة على مبيعاتك. لن ألمس أي سير عمل قائم.

## 2. القرار الأساسي: تطوير لا إعادة بناء
الكود الحالي يصلح نواةً لمرحلة الإنتاج. سأحوّله من "سكربت يومي" إلى **مكتبة وحدات + طابور مهام**، وأضيف حوله طبقات: استراتيجية، تحليل، قاعدة بيانات، لوحة تحكم، إشعارات.

## 3. البنية التقنية

```
┌─ n8n (منفصل) ── المُنسّق: جداول زمنية، webhooks، تنبيهات Telegram، موافقات
│        │ HTTP
│        ▼
│  Core API (Python/FastAPI) ◄──── Dashboard (Web, RTL عربي)
│        │
│        ├─ Strategy   : niche/كلمات/منافسين/تقييم الأفكار/خطة محتوى
│        ├─ Research   : جمع مصادر + تلخيص + تحقق (مع روابط المصادر)
│        ├─ Writer     : سيناريو + خطاف 5 ثوانٍ + تعليق (Claude)
│        ├─ Media      : صوت + صور/فيديو AI + موسيقى مرخصة
│        ├─ Editor     : ffmpeg مونتاج/ترجمة/Shorts
│        ├─ QA Gate    : بوابة جودة آلية + مراجعة بشرية
│        ├─ Publisher  : YouTube Data API
│        └─ Analytics  : YouTube Analytics API + حلقة التعلّم
│        ▼
│  Postgres (Supabase مجاني أو VPS)  +  تخزين ملفات (Drive/R2)
└─ Worker (VPS صغير أو GitHub Actions) ينفّذ المهام الثقيلة (ffmpeg)
```

**لماذا هذا التقسيم؟** n8n ممتاز للجدولة والربط والإشعارات، لكنه سيئ لمعالجة الفيديو والمنطق المعقد. لذا المنطق في بايثون (قابل للاختبار والتوسع)، وn8n يستدعيه فقط. إن تعطّل n8n يبقى خط الإنتاج قابلاً للتشغيل يدوياً.

**الاستضافة:** الخيار الموصى به VPS صغير (4GB، ~5–15$/شهر) يشغّل Docker Compose: Core + Worker + Postgres + n8n. بديل أرخص للبداية: GitHub Actions للعمل الثقيل (كما هو الآن) + Supabase المجاني.

**قاعدة البيانات (جداول رئيسية):** `niches`, `ideas` (درجات)، `content_plan`, `videos` (حالة: idea→researching→scripted→rendering→review→approved→scheduled→published)، `assets`, `costs` (تكلفة كل خطوة)، `publish_log`, `metrics_daily`, `experiments` (عناوين/صور)، `automation_log`, `errors`، `settings` (مفاتيح التشغيل/الإيقاف). لغة كل سجل حقل مستقل، فالدعم متعدد اللغات من اليوم الأول.

**معالجة الأخطاء:** كل خطوة idempotent وتُسجَّل نتيجتها؛ إعادة محاولة بتأخير تصاعدي (3 مرات) لأخطاء الشبكة/الحصص؛ بعد الفشل تُوقف الخطوة وتصلك رسالة Telegram بالسبب وزر "أعد المحاولة"؛ مفتاح إيقاف شامل (kill switch) قبل أي نشر.

## 4. سير العمل من الفكرة إلى التحليل

1. **اكتشاف (يومي):** جمع إشارات من YouTube Data API (فيديوهات رائجة في الـniche، قنوات منافسة، اقتراحات البحث) + بيانات قناتي الخاصة.
2. **تقييم الفكرة:** درجة من 100 = طلب (حجم بحث/نمو) + منافسة (جودة وعمر النتائج الحالية) + ملاءمة القناة + قيمة إعلانية + كلفة الإنتاج + عدم التكرار مع فيديوهاتنا. تُخزَّن الدرجة مع الأسباب.
3. **خطة المحتوى:** أسبوعية/شهرية تُنتجها الخوارزمية وتعرضها عليك للتعديل.
4. **بحث وتحقق:** مصادر موثوقة، كل ادعاء رقمي أو واقعي يُربط برابط مصدر؛ ما لا مصدر له يُحذف. (الكود الحالي يتجنب الأرقام لهذا السبب؛ سنعالجه بالتحقق لا بالتجنب.)
5. **سيناريو:** خطاف أول 5 ثوانٍ، ثم هيكل بالتعليق الصوتي، ثم مراجعة ذاتية من Claude بقائمة معايير (قيمة جديدة؟ تكرار؟ تضليل؟).
6. **صوت:** ElevenLabs (أو بديل بعد اختبار سماعي لثلاثة أصوات عربية).
7. **مرئيات:** مزيج: لقطات شاشة حقيقية للأدوات (ملف مصدر مرخّص/مسجّل مني)، رسوم/إنفوغراف مولّدة، صور AI، ومقاطع AI قصيرة للمشاهد المميزة فقط. لا لقطات ستوك عامة وحدها (أهم سبب للمظهر الرخيص).
8. **مونتاج:** ffmpeg: انتقالات، حركة (Ken Burns)، ترجمة متزامنة، موسيقى بخفض تلقائي عند الكلام، 1080p (4K اختياري لاحقاً).
9. **بوابة الجودة:** فحوص آلية (مدة، مستوى الصوت LUFS، تطابق الترجمة، وجود مصادر، ترخيص الموسيقى، فحص تشابه مع فيديوهاتنا) ثم **موافقتك** في اللوحة.
10. **تصغير:** 3 صور مصغرة مرشّحة؛ وتجربة A/B على العنوان والصورة بعد النشر.
11. **نشر:** رفع خاص ← موافقتك ← جدولة. السجل الكامل في `publish_log`.
12. **تحليل:** سحب المقاييس يومياً، تقرير أسبوعي، وتغذية رجعية لخطة المحتوى.

## 5. الطويل والقصير (الاستراتيجية الموصى بها)
- **2 فيديو طويل أسبوعياً** (8–12 دقيقة) كأساس لساعات المشاهدة والإيراد.
- **من كل طويل: 3–4 Shorts**، لكن **بإعادة كتابة وإخراج عمودي**، لا اقتطاع آلي أعمى: كل Short له خطاف وخاتمة وقيمة مستقلة، ويحيل للفيديو الكامل.
- Shorts إضافية من أفكار مستقلة سريعة (نصيحة/أداة) بعدد محدود.
- **النسبة:** الطويل يبني الإيراد والثقة، والقصير يبني الاكتشاف. أبدأ بـ 2 طويل + 6 Shorts أسبوعياً ونعدّل بالبيانات.

**قيود YouTube التي يجب معرفتها (تؤثر على التصميم):**
- مشاريع Google Cloud غير الموثّقة يُجبَر ما ترفعه على **خاص**؛ يلزم طلب **API Compliance Audit** كي يصبح النشر العام والمجدول ممكناً. هذا يحدد مسار البداية: كل شيء خاص + نشر يدوي أو بعد الموافقة حتى يُقبل الطلب.
- حصة اليوم 10,000 وحدة؛ الرفع ≈1,600، والبحث 100 لكل طلب. يكفي لـ 3–4 رفعات يومياً وبحث محدود، فنخزّن النتائج مؤقتاً.
- الإفصاح عن المحتوى الاصطناعي الواقعي إلزامي (مفعّل في الإعدادات).
- لا أستخدم أي وسيلة التفاف أو أتمتة واجهة؛ فقط واجهات رسمية.

## 7. تحقيق الدخل والمخاطر (بصراحة)
- **شروط الشراكة:** المسار الكامل 1000 مشترك + 4000 ساعة مشاهدة (12 شهراً) أو 10 ملايين مشاهدة Shorts (90 يوماً)؛ وهناك مستوى مبكر بشروط أقل (500 مشترك + 3000 ساعة أو 3 ملايين Shorts) يتيح الاشتراكات والمتجر لا الإعلانات. تُراجَع الأرقام على صفحة YouTube الرسمية عند التطبيق.
- **الخطر الأكبر:** سياسة "المحتوى غير الأصيل/المكرر" في YPP. قنوات الأتمتة الكاملة بصوت AI وستوك معرّضة لرفض الأهلية. لذلك التصميم يفرض: بحث وقيمة أصلية، لقطات شاشة وشروحات حقيقية، قالب غير متكرر، **مراجعة بشرية على كل فيديو في المرحلة الأولى**، وحد أقصى للإنتاج الأسبوعي. التأكيد: لا أستطيع وعدك بقبول القناة، لكن هذه هي الممارسات التي تقلل الخطر.
- **الإيراد المتوقع:** لا أقدّم رقماً. اللوحة ستحسب **تكلفة الفيديو مقابل RPM الفعلي** بعد توفره، وتعرض نقطة التعادل.
- **التسويق بالعمولة/الرعايات:** مرحلة لاحقة، بعد ~1,000 مشترك؛ حقل روابط العمولة مدعوم في الوصف من البداية مع إفصاح.

## 10. أسئلة تحتاج قرارك
1. **المجال:** أكمل بـ "الذكاء الاصطناعي والتقنية للجمهور العربي" (TECH4U) أم نجري دراسة niche أولاً؟ (الأخيرة تتطلب بيانات؛ أقترح 3 مرشحين نقارنهم بالأرقام.)
2. **الاستضافة:** VPS (موصى) أم GitHub Actions + Supabase للبداية؟
3. **n8n:** نسخة جديدة منفصلة (موصى) أم مشروع معزول في نسختك الحالية؟
4. **سقف الميزانية الشهرية** المقبول، وهل يُسمح بتوليد فيديو AI أم صور فقط في البداية؟
5. **هل لديك** مفاتيح Anthropic وElevenLabs وقناة يوتيوب جاهزة ومشروع Google Cloud؟ (لن أطلب منك لصق أي مفتاح في المحادثة؛ تُضاف كأسرار.)
6. **الوجه/الصوت:** قناة بلا وجه بصوت AI عراقي مقبولة، أم تفضّل صوتك المسجّل لأجزاء مميزة؟
