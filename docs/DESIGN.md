**ما لن يتحقق بميزانية صفرية، وأقولها بصراحة:**
- جودة صوت بمستوى ElevenLabs. أفضل ما أتوقعه "مقبول إلى جيد"، وسنقرر باختبار سماعي.
- فيديو/صور AI عالية الجودة. سنعوّضها بتصميم بصري برمجي ولقطات شاشتك الحقيقية، وهي أصلاً أفضل لقناة تقنية وأقل خطراً على أهلية الربح.
- بيانات كلمات مفتاحية بجودة vidIQ. سنعتمد إشارات يوتيوب الرسمية ونعدّل بالنتائج الفعلية.
- سرعة إنتاج عالية: الفيديو الطويل قد يأخذ ساعة أو أكثر على جهازك (حسب مواصفاته). لا بأس لأنه يعمل في الخلفية.
- لا أضمن قبول القناة في برنامج الشراكة؛ القيمة الأصلية ومراجعتك لكل فيديو هما أفضل حماية.

## 2. جهازك (تم الفحص بنتيجة أرسلتها أنت)
Windows 11 · Intel Core i5-10300H (4 أنوية / 8 خيوط) · **GTX 1650 (4GB VRAM)** · 15.9GB RAM · 345GB حرة · **Docker غير مثبّت** · غالباً لابتوب.

**ما يعنيه ذلك:**
- **Whisper:** `small` أو `medium` بتكميم int8 يناسب 4GB VRAM (يُجرَّب على GPU ثم CPU كبديل). مقبول.
- **TTS:** Piper (CPU) هو الأساس العملي. Chatterbox يحتاج ذاكرة GPU أكبر من 4GB عادةً، فيُجرَّب مرة واحدة على CPU وغالباً سيكون بطيئاً جداً للفيديو الطويل.
- **توليد الصور محلياً:** 4GB تكفي لـ Stable Diffusion 1.5 بدقة صغيرة فقط، بجودة متواضعة وبطء على هذه البطاقة. **يبقى معطلاً** ولا أعتمد عليه؛ المرئيات بالرسوم البرمجية ولقطات الشاشة.
- **Docker Desktop:** يلزم تثبيته (مجاني للاستعمال الشخصي) مع WSL2؛ أحدّ ذاكرة WSL إلى ~4GB كي لا يضغط على جهازك. بديل إن رفضت التثبيت: تشغيل n8n عبر Node مباشرة (يخالف شرط Docker فلا أفعله دون موافقتك).
- **بطارية:** المعالجة الثقيلة (Whisper/ffmpeg) تعمل افتراضياً والجهاز موصول بالشاحن، وتتوقف مؤقتاً على البطارية.
- **ترتيب الإنتاج:** مرحلة واحدة ثقيلة في كل مرة، بأولوية منخفضة.

## 3. البنية

```
 جهازك (Windows)
 ├─ Docker:  n8n Community  ──HTTP──┐   (جدولة، سلاسل العمل، عرض الأخطاء)
 ├─ Python (محلي مباشرة، ليس داخل Docker):
 │    Core API + Worker  ◄───────────┘
 │     ├ research/  scoring/  planner/        (استراتيجية)
 │     ├ script_gen (موجود) + budget guard    (Claude)
 │     ├ tts (واجهة موحدة) + whisper-align    (صوت + ترجمة)
 │     ├ visuals (موجود) + motion graphics    (مرئيات)
 │     ├ render (موجود) + short render        (مونتاج)
 │     ├ upload (موجود) + analytics           (يوتيوب)
 │     └ telegram_bot (long-polling)          (مراجعة وموافقة)
 ├─ SQLite: videos, ideas, plan, costs, ledger, metrics, logs, settings
 └─ Dashboard محلية: http://localhost:8080 (صفحة RTL بلا بناء Node)
```
**قرارات مهمة وأسبابها:**
- Python يعمل خارج Docker كي يستعمل ffmpeg وCPU/GPU مباشرة وبلا بطء ملفات WSL.
- بوت Telegram يعمل **بالاستطلاع (long-polling)** لا Webhook، لأن n8n المحلي غير قابل للوصول من الإنترنت ولا نريد أنفاقاً (tunnels). لذلك Telegram Trigger في n8n غير مناسب هنا.
- n8n يقوم بالجدولة واستدعاء مراحل Python وإشعار الأخطاء. إن تعطل يبقى كل شيء قابلاً للتشغيل من اللوحة أو سطر الأوامر.
- **آلة حالات** لكل فيديو محفوظة في SQLite: idea → researched → scripted → voiced → rendered → review → approved → uploaded → measured. أي إطفاء مفاجئ يستأنف من آخر مرحلة منتهية.

## 4. سير العمل (من الفكرة إلى التحليل)
1. **اكتشاف أفكار** (محلي، 0 رصيد): Hacker News وGitHub وRSS مدونات تقنية + `videos.list?chart=mostPopular` (يكلف وحدة واحدة) + قنوات المنافسين (`channels`/`playlistItems` وحدة واحدة لكل طلب). `search.list` يكلف 100 وحدة، فيُستعمل بحد يومي.
2. **تقييم** (قواعد محلية، 0 رصيد): درجة من 100 = زخم الموضوع + أداء مشابه عند المنافسين نسبةً لحجم قناتهم + عدم التكرار مع قناتنا + ملاءمة الجمهور + سهولة الإنتاج المجاني. تُخزَّن الأسباب مع الدرجة.
3. **خطة أسبوعية** تُعرض عليك للتعديل.
4. **سيناريو أصلي:** استدعاء Claude واحد لكل فيديو (+ استدعاء إصلاح عند الحاجة)، مع ملاحظات بحث تُجمع محلياً مع روابطها. لا أرقام بلا مصدر.
5. **صوت** عبر TTS محلي ← **Whisper** يستخرج توقيت الكلمات من الصوت الناتج ← ترجمة ASS (يدخل بدل توقيت ElevenLabs دون تغيير بقية الكود).
6. **مرئيات:** مشاهد رسوم برمجية (عناوين متحركة، قوائم، مخططات، مقارنات) + لقطات ستوك مرخّصة + لقطات شاشتك عند توفرها.
7. **مونتاج** ffmpeg + موسيقى مرخصة (YouTube Audio Library، تُحمَّل يدوياً مرة واحدة ويُسجَّل ترخيصها).
8. **Short:** يُشتق من نفس البحث والمواد مع إعادة كتابة قصيرة (استدعاء Claude صغير) وإخراج عمودي 9:16؛ لا قص أعمى للفيديو الطويل.
9. **بوابة جودة آلية:** المدة، مستوى الصوت، تطابق الترجمة، وجود مصادر، فحص تشابه عنوان/نص مع فيديوهاتنا، ترخيص الموسيقى.
10. **إرسال للمراجعة (Telegram):** صورة مصغرة + العنوان والوصف + ملخص السيناريو + **معاينة 480p**. حد رفع ملفات البوت 50MB، فالفيديو الكامل يُفتح من اللوحة المحلية. أزرار: ✅ موافقة · ✏️ تعديل · ❌ رفض.
11. **رفع بعد موافقتك** (القسم 5) وتسجيل الرابط.
12. **تحليل يومي/أسبوعي:** مشاهدات، مدة المشاهدة، CTR، الاحتفاظ، مصادر الزيارات. تقرير أسبوعي (يُولَّد محلياً بلا Claude) يغذّي خطوتي 2 و3.

## 5. قيود يوتيوب (تؤثر على التصميم)
- **مشاريع API غير الموثّقة تُجبَر على الرفع كـ"خاص".** طلب الـ Compliance Audit مجاني لكنه يستغرق وقتاً. حتى يُقبل: النظام يرفع **خاصاً**، وأنت تضغط "جدولة/نشر" في YouTube Studio (30 ثانية). بعد القبول تُفعَّل الجدولة الآلية بإعداد واحد.
- **فخ التوكن:** تطبيق OAuth في وضع "Testing" ينتهي refresh token بعد 7 أيام. الحل المجاني: نقل التطبيق إلى "In production" (بقاؤه غير موثّق يعني شاشة تحذير لك أنت فقط، وهو مقبول لاستعمال شخصي).
- حصة 10,000 وحدة يومياً، الرفع ≈1,600 وحدة: تكفي رفعتين يومياً مع بحث محدود.
- ضبط الصورة المصغرة يتطلب توثيق قناتك بالهاتف (مجاني).
- كل ما سبق عبر واجهات رسمية فقط، بلا التفاف.

## 6. ميزانية Claude (5$) — حارس صارم
- **سجل (ledger) في SQLite** يسجل كل استدعاء بالتوكنات الفعلية من حقل `usage` في الرد، مضروبة بجدول أسعار في `config.yaml`. **أتحقق من الأسعار من الصفحة الرسمية قبل أول استدعاء وتوافق أنت عليها**؛ لا أعتمد على ذاكرتي.
- **فحص قبل كل استدعاء:** أسوأ حالة = (توكنات الإدخال المحسوبة بـ `count_tokens`) + (`max_tokens` × سعر الإخراج). إن لم تتسع في الرصيد المتبقي ← **يُمنع الاستدعاء** ويصلك تنبيه.
- **سقف صلب 4.00$** (يبقى 1$ احتياطاً لفرق الحساب)، وتحذير عند 3.00$. لا يمكن لأي مرحلة تجاوزه، والكود لا يحتوي مساراً يتجاوز الحارس.
- **الرصيد الفعلي هو الموجود في Console**، والسجل المحلي تقدير؛ تراجع Console بعد أول يوم، وأقترح ضبط حد إنفاق هناك أيضاً إن كان متاحاً.
- **سياسة الاقتصاد:** Claude لخطوتين فقط: السيناريو الطويل (أعلى قيمة) والـ Short. كل شيء آخر (أفكار، تقييم، تقارير، عناوين بديلة) محلي بقواعد، أو بنموذج محلي (Ollama) إن كان جهازك يسمح، أو Gemini عبر خطة AI Studio المجانية **إن كان مفتاحك بلا بطاقة دفع** (أسألك عن هذا؛ ولا أعتبره مجانياً قبل التأكد، وحدوده تتغير وقد تُستعمل البيانات لتحسين المنتج).
- **تقدير إرشادي:** سيناريو عربي طويل ≈ 3–5 آلاف توكن إخراج، فالكلفة بين بضعة سنتات وعشرة سنتات حسب الفئة. هذا يعطي **عشرات السيناريوهات** من 4$ لا مئات. لذلك أقترح استعمال أرخص نموذج يعطي عربية مقبولة ونقارن عينة واحدة بموافقتك قبل اعتماده.
- وضع **dry-run** (موجود) يعمل بلا أي رصيد، ونستعمله لاختبار كل المونتاج والصوت والترجمة.

## 7. الصوت العربي: خطة الاختبار (قبل أي اعتماد)
مرشحون، ويلزم **التحقق من الترخيص التجاري لكل صوت** لأن القناة ستُربح:
| المرشح | الملاحظة |
|---|---|
| Piper (محلي، كود MIT) | خفيف ويعمل على أي جهاز؛ نطق عربي أقل طبيعية؛ ترخيص كل صوت يُفحص منفصلاً |
| Chatterbox Multilingual (مفتوح، يدعم العربية حسب علمي) | جودة أعلى، لكن يحتاج جهازاً أقوى (يفضَّل GPU)؛ أتحقق من الدعم والترخيص |
| edge-tts (أصوات Microsoft العصبية) | أجمل الموجود مجاناً، **لكنه يستعمل نقطة غير رسمية** لخدمة Edge، بلا ضمان استمرار ولا وضوح ترخيص للمحتوى المُربح. **لا أعتمده افتراضياً**؛ يمكن استعماله للاختبار المقارن فقط وقرارك بعد عرض المخاطر |
| مستبعدة | XTTS-v2 (ترخيص غير تجاري)، MMS-TTS (CC-BY-NC)، ElevenLabs المجاني (غير تجاري)، Google/Azure TTS (تتطلب بطاقة دفع) |

**الاختبار:** جملة افتتاحية + فقرة شرح + أرقام وأسماء إنجليزية (ChatGPT, Claude) بكل مرشح، تسمعها أنت (الحكم لك على اللهجة والطبيعية)، ونقيس زمن التوليد على جهازك. المعيار: الوضوح ونطق الأسماء الإنجليزية والترخيص ثم الجمال.

### قرار الصوت (بعد التحقق من التراخيص)
| النموذج | الترخيص | الحكم |
|---|---|---|
| **SILMA TTS v1** (150M) | كود MIT، **أوزان Apache-2.0**، "مُدرَّب من الصفر" حسب مطوّريه، ويصرّحون بالاستخدام التجاري | ✅ **المرشح المعتمد مبدئياً.** ثنائي اللغة عربي/إنجليزي (يحل مشكلة أسماء ChatGPT/Claude)، يستنسخ صوتاً من مرجع قصير، 150M يناسب 4GB |
| Habibi-TTS IRQ (لهجة عراقية) | بطاقته تقول Apache للـIRQ، لكن حقل الترخيص الرسمي CC-BY-NC-SA، وهو **مُهيَّأ من أوزان F5-TTS (CC-BY-NC)** حسب ورقتهم | ❌ **غير معتمد للقناة المُربحة**؛ يجوز للتجربة غير التجارية فقط، ولا أعتمده إلا بتوضيح كتابي من مطوّريه |
| Piper `ar_JO-kareem` | ترخيص بياناته غير موثّق ("See URL") ولم أستطع الوصول لمصدره | ⚠️ احتياطي فقط حتى يُتحقق |
| Chatterbox Multilingual | MIT حسب مصادره | ⏸ مؤجل: يحتاج ذاكرة GPU غير مؤكدة |
| ElevenLabs (صوت `7N1xLmvR6jQolMXWRhvT`) | الخطة المجانية غير تجارية | 🗂 محفوظ في `config.yaml` كخيار مستقبلي، لا حذف ولا استدعاء تلقائي |

**قرار المالك بعد الاستماع:** نبرة صوته صحيحة لكن النطق واللهجة فيهما أخطاء؛ بين 4 إعدادات اختار **D** (بلا تشكيل آلي، nfe=32) كخيار **مقبول مؤقتاً**. يُعاد التقييم بالفيديو التجريبي؛ البدائل المطروحة: مرجع بالفصحى، أو Habibi للتجربة فقط.
**اللهجة العراقية:** SILMA لا يملك صوتاً عراقياً جاهزاً، لكنه يستنسخ **نبرة وأسلوب** المقطع المرجعي. لذا نستعمل **تسجيلك أنت** بلهجتك. ما سيكسبه من لهجتك غير مضمون، وهذا ما يحسمه الاستماع. صوتك أصلاً يحل مسألة الموافقة على الاستنساخ التي يشترطها ترخيص SILMA.
**أُجريت تجربة تقنية على CPU السحابة بمرجع آلي (لا صوتك):** يعمل، والتحميل ≈50ث، ومعدل التوليد ≈ 4.7–5.2× زمن الصوت على 4 أنوية. فيديو 8 دقائق ≈ 40 دقيقة على CPU؛ **على GTX 1650 غير مقاس بعد** وأتوقعه أسرع بوضوح. الجودة لا يمكنني الحكم عليها بأذني.
**مخاطرة تبقى:** ترخيص الأوزان نظرياً تصريح من المطوّر؛ لا أستطيع تدقيق بيانات تدريبه (جزء منها "proprietary" حسب بطاقتهم). نقبل هذا الخطر أو لا؛ هذا قرارك.

## 8. المرئيات بلا توليد AI
- **رسوم برمجية** (Pillow + matplotlib + ffmpeg): عناوين متحركة، خطوات مرقمة، جداول مقارنة، رسوم بيانية من بيانات موثقة. أصلية 100%.
- **لقطات شاشة حقيقية** لأدوات الذكاء الاصطناعي تسجّلها بـ OBS (مجاني) أو تسجيل Windows؛ النظام يقص ويضيف التكبير والتعليقات. هذا أقوى عنصر ضد "المحتوى المكرر".
- **ستوك Pexels/Pixabay** (مجاني، ترخيصه يسمح بالاستعمال التجاري، والكود الحالي يعمل به) كعنصر مكمّل فقط.
- **توليد صور محلي** (Stable Diffusion/Flux مفتوحة) مؤجل: يحتاج GPU فعلي، وسأقرره بعد معرفة مواصفاتك. على CPU غير عملي.
- ممنوع: أي خدمة توليد مدفوعة، شعارات وصور بلا ترخيص.

## 10. التشغيل التلقائي والإيقاف/الاستئناف
- n8n: Docker Desktop (مجاني للاستعمال الشخصي) بتشغيل تلقائي مع Windows، `restart: unless-stopped`.
- Python: مهمة في Windows Task Scheduler عند تسجيل الدخول؛ **تعويض الفائت:** عند الإقلاع يفحص الجدول ويشغّل ما فاته إن كان مناسباً.
- مفتاح `paused` في SQLite، وأزرار في اللوحة وفي Telegram (`/pause` `/resume`)؛ إيقاف النشر مفتاح مستقل عن إيقاف الإنتاج.
- أولوية منخفضة لعمليات ffmpeg/Whisper كي لا يُبطئ جهازك، وعمل واحد في كل مرة.
- لا تستطيع الأتمتة العمل والجهاز مطفأ؛ هذا قيد جوهري من شرط عدم الاستضافة.
